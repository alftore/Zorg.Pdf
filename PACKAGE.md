# Zorg.Pdf

Async-first PDF generation for .NET 10, written in C# only, with no native binaries and no dependencies. Native AOT and trimming work.

**Early development: there is nothing usable in this package yet, and the API will change before 1.0.**

## Planned

- Documents and reports from code, a JSON document model, or templates and data
- Async resource loading, `IAsyncEnumerable` table rows, streamed output, cancellation
- Tagged PDF by default, with PDF/UA and PDF/A
- Tools for AI agents through Microsoft.Extensions.AI
